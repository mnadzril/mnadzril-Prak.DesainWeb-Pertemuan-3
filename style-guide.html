MINI STYLE GUIDE

1. Opsi Font

Opsi A — Times New Roman (serif): Digunakan untuk tampilan formal dan akademik.

Opsi B — Arial (sans-serif): Digunakan untuk tampilan modern dan mudah dibaca di layar.

2. Warna

Warna Utama — #003366 (HEX)
Warna Sekunder — rgb(0,102,153)
Warna Aksen — hsl(30,100%,50%)
Variasi Transparan — rgba

3. Ukuran Heading

H1 = 32px

H2 = 24px

H3 = 20px

Body / Paragraf = 16px

4. Line Height

Contoh line-height 1.4 — rapat, cocok untuk teks pendek dalam kartu atau tombol pada halaman web.

Contoh line-height 1.8 — renggang, cocok untuk paragraf panjang agar nyaman dibaca di layar desktop maupun mobile.
